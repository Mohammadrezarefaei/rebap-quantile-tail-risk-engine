# rebap-quantile-tail-risk-engine
Probabilistic energy forecaster &amp; imbalance cash-exposure engine for German power markets (reBAP). Implements asymmetric pinball loss (P10/P50/P90) and tail-risk stress testing using Value at Risk (VaR) &amp; Conditional Value at Risk (CVaR). Built with LightGBM, Streamlit &amp; automated CI/CD.
